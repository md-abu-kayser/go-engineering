# Code of Conduct

## Our commitment

Go Engineering is intended to be a welcoming place for beginners, experienced developers, reviewers, maintainers, and curious people from different technical backgrounds.

We are committed to providing a professional environment where people can ask questions, disagree about technical decisions, and improve the project without personal hostility.

## Expected behavior

Participants are expected to:

- communicate respectfully;
- assume good intent while still addressing technical problems directly;
- focus criticism on code, documentation, architecture, and decisions rather than people;
- welcome beginner questions;
- explain trade-offs instead of dismissing alternatives;
- protect private information and credentials;
- give appropriate credit for external ideas and contributions.

## Unacceptable behavior

The following are not acceptable:

- harassment or personal attacks;
- discriminatory or hateful language;
- threats, intimidation, or deliberate disruption;
- publishing another person's private information without permission;
- malicious changes intended to compromise contributors or users;
- repeated bad-faith behavior after maintainers have asked for it to stop.

## Maintainer responsibilities

Maintainers are responsible for clarifying project standards, reviewing contributions fairly, and taking reasonable action when behavior violates this code.

Moderation decisions should focus on protecting a productive engineering environment rather than winning technical arguments.

## Reporting concerns

For sensitive conduct issues, contact the repository owner privately rather than continuing the dispute in a public issue or pull request.

Security vulnerabilities should follow the process in [`SECURITY.md`](./SECURITY.md).

## Scope

This code applies to repository spaces and project activities where participants are representing or interacting with the Go Engineering community.

## Final note

A high-quality engineering community is built through curiosity, precision, patience, and mutual respect. Thank you for helping make the repository useful to the next person who discovers it.
