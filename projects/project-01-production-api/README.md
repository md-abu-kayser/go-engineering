# Production API

HTTP API with validation, structured errors, database boundary, tests, observability hooks, and graceful shutdown.

This project is a capstone exercise, not a tutorial toy. Design decisions should be documented, tested, measured, and revisited as requirements evolve.

## Expected engineering concerns

- correctness and explicit failure handling
- context propagation and timeouts
- clean dependency boundaries
- deterministic tests
- structured logs and metrics
- security and data minimization
- graceful shutdown
- operational documentation
