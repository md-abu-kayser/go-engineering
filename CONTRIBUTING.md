# Contributing

This repository treats every lesson as a small, reviewable engineering artifact. Prefer one concept per example, explicit error handling, deterministic output, and tests where behavior is non-trivial.

## Workflow
1. Create or improve a lesson under the correct level.
2. Run `gofmt`, `go vet`, and `go test ./...`.
3. Keep APIs small and comments focused on why, not what.
4. Update the relevant README/checklist when a new topic is introduced.

See the root README for the learning philosophy and contribution standards.
