# Level 12 — Production Engineering

This level contains **59 focused Go lessons**. Each numbered directory is intentionally isolated so the example can be read, run, tested, and extended without navigating a monolithic demo program.

## Learning contract

- Read the local `README.md` before coding when present.
- Run the example with `go run .` from a lesson directory.
- Change one thing, observe the behavior, then explain it in your own words.
- Prefer the standard library and small interfaces before adding dependencies.
